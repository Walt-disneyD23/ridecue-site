Support

One person builds RideCue. Write and you'll get a real reply.

support@ridecue.live

Include the Version line from Settings (it reads build 0728cd or similar) and a screenshot if something looks wrong. That's usually enough to find it.

Alerts aren't arriving

Allow notifications when RideCue asks, and check they're still allowed for RideCue in iOS Settings. If the master switch inside RideCue is off, nothing is sent.

A wait doesn't match the Disney app

RideCue refreshes live waits every 3 minutes while parks are open, from ThemeParks.wiki — or pull down any time. Disney's app is the source of record; if the two disagree, trust Disney's.

Starting over

Turn alerts off, then delete the app. Everything RideCue kept is gone.
